# Glosario inicial

| Término | Definición de trabajo |
| --- | --- |
| SECOP | Sistema Electrónico para la Contratación Pública de Colombia. |
| SECOP II | Plataforma transaccional donde las entidades gestionan procesos y contratos electrónicos. |
| Proceso de contratación | Conjunto de actuaciones mediante las cuales una entidad adelanta una compra pública, se adjudique o no. |
| Contrato | Acuerdo registrado como resultado de un proceso de compra, con partes, valor, plazo y estado. |
| Entidad | Organismo estatal que publica o gestiona el proceso de contratación. |
| Proveedor | Persona natural, jurídica o agrupación que participa o contrata con una entidad. |
| Modalidad | Procedimiento utilizado para seleccionar al contratista. |
| UNSPSC | Clasificación estandarizada de bienes y servicios utilizada para categorizar compras. |
| Socrata | Plataforma que expone los conjuntos de Datos Abiertos Colombia mediante API. |
| Ingesta | Obtención controlada de datos desde una fuente externa. |
| Normalización | Conversión de valores externos a formatos internos consistentes. |
| Idempotencia | Propiedad por la cual repetir una carga produce el mismo estado sin duplicados. |
| Indicador o señal | Condición objetiva que puede justificar revisión adicional. |
| Puntaje de riesgo | Combinación explicable de señales; no es probabilidad de corrupción. |
| Evidencia | Valores y referencias que permiten verificar por qué se activó una señal. |
| Vigencia | Periodo fiscal o anual utilizado para delimitar el análisis. |
